# 被商家坑了，去 12315 该投诉还是举报？

[人生黑客](../../README.md) › [全部的题](../README.md) › [消费与合同](README.md)

问答题 · 简单 · 避免损失 · 与商家发生消费争议的人
依据：法规原文 · 核对于 2026-10-17 · 全国通用，限市场监管部门职责范围内的生活消费争议和经营者涉嫌违法线索

**答案**　看你要的是什么。想让商家给你退、换、赔，把你自己这桩消费纠纷了结，选投诉；想让监管部门去查商家涉嫌违法的事，选举报。两样都想要，就两样一起提，市场监管部门得分开处理，投诉走投诉的程序，举报走举报的程序。投诉要写清三样东西：你是谁，也就是姓名、电话和通讯地址；你告的是哪家，写它的名称和地址；你要它做什么，争议是怎么回事、有什么凭据。举报要给的是具体的线索和事实依据。最容易落空的是只填一张投诉单，末尾加一句"请依法查处"，以为这就算举报了。两样都要办，就把"我要商家解决什么"和"商家涉嫌什么违法、证据是什么"分开写清楚。还要有个预期：市场监管部门处理投诉用的是调解，你和商家都同意才调得起来。提交的路就几条：全国 12315 平台、12315 热线电话，或者市场监管部门公布的邮寄地址和受理窗口。

## 解析

投诉解决的是你自己的事。前提是你为了生活消费买东西、用东西或者接受服务，跟商家起了争议，请市场监管部门帮你把这个争议解决掉。买来做生意用的，不算这里的投诉。写投诉的时候，请求要具体，退多少、换什么、赔什么，直接写出来，再把事情经过和能证明它的凭据附上。材料要是真的，你得对它负责。市场监管部门要核对你的身份，可以让你补身份证明，所以姓名、电话、地址别乱填。

投诉之后，市场监管部门是在你和商家都同意的前提下组织调解，法律、法规另有规定的按那边的规定。也就是说，它是把你们两边拉到一起谈，商家点头了才谈得起来。你心里有这个预期，写请求时就别漫天要价，写一个你真能接受的方案。

举报不要求你是吃亏的那个人。任何人、任何单位，发现商家涉嫌违反市场监管的法律、法规、规章，都可以报。它解决的不是你的退款，是让监管部门去查这家商家。举报最要紧的是线索具体：哪家店、哪天、卖了什么、哪里涉嫌违规、你手上有什么证据。笼统一句"这家店坑人"，监管部门没法查。举报的内容同样要真实，你要对它负责。

举报人的信息受保护。市场监管部门不能把你的个人信息和举报处理的情况透露给被举报的商家，也不能告诉跟处理举报无关的人。只有一个例外：你交的材料里投诉和举报混在一起，组织调解又需要让商家知道某些信息，调解必需的那部分可以给商家。所以你既想要回自己的钱、又不想让商家知道是谁举报的，这一点要先想清楚，两件事各写各的，别搅在一份材料里。

两样一起提，在 12315 平台上按页面提示填写，把你的请求、涉嫌违法的具体线索和事实依据写清楚。同一份材料里两类内容都写清楚了，市场监管部门也得分别处理；只加一句"请依法查处"，不能代替举报所需的具体线索和事实依据。拿不准平台怎么填的，打 12315 热线，直接说你既要投诉又要举报，让接线员确认是分别记下的。

有些事不归市场监管部门管。这套投诉举报的办法管的是市场监管部门职责内的事，法律、法规、规章规定由别的部门处理的，按那边的规定去找那个部门。

举报之后多久核查、多久告诉你结果，提交后直接问受理你举报的那个市场监管部门，问清它按什么规定处理、什么时候告知你。

- 市场监管部门应对举报人的信息保密，不得向被举报人或者与举报处理无关的人员泄露举报人个人信息、举报处理情况等；但材料同时包含投诉和举报内容且需向被举报人提供组织调解所必需信息的除外（市场监督管理部门处理举报；材料同时包含投诉和举报内容，并且需要向被举报人提供组织调解所必需信息的情形除外）[1] 第三十七条
- 这套投诉举报程序适用于市场监管部门依职责处理的事项；法律、法规、规章规定由其他部门处理的，依照相应规定（市场监督管理部门依照职责处理投诉举报；法律、法规、规章规定由其他部门处理的事项除外）[1] 第二条
