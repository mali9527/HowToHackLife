- **[没领证就分手了，彩礼怎么要回来？](0012.md)**（第 0012 题 · Hot 100 第 75 名）  
  没领证、也没真正一起过日子就分了，彩礼可以要回来，去法院起诉，法院会支持退。
- **[结婚登记必须回户籍地、带户口簿吗？](0086.md)**（第 0086 题 · Hot 100 第 64 名）  
  不用。
- **[父母出钱给我买房，离婚时这套房怎么分？](0087.md)**（第 0087 题 · Hot 100 第 74 名）  
  不是一人一半，要看父母是什么时候出的钱、出了多少、当时说没说送给谁。
- **[婚前买的房，婚后加了对方的名字，离婚时怎么分？](0088.md)**（第 0088 题）  
  加了名不等于离婚就一人一半。
- **[国家育儿补贴每年 3600 元，怎么领？](0089.md)**（第 0089 题）  
  由爸爸或妈妈中的一个人，向孩子户口所在的地方申请，网上在支付宝、微信的"育儿补贴"小程序或者孩子户籍所在省份的政务服务平台就能办，不会弄的去孩子户籍地的乡镇政府或街道办事处当面办。
- **[领证没多久就离了，彩礼能要回来吗？](0090.md)**（第 0090 题）  
  要不要得回来，不看领证多久，看你们有没有真的一起过日子。
- **[分居满一年、两年，就能判离婚吗？](0091.md)**（第 0091 题）  
  光分开住够时间，婚离不掉，法院也不是到了日子就判。
- **[婚后继承父母的房子，离婚时要分给对方吗？](0268.md)**（第 0268 题）  
  默认要分。
- **[配偶在外面借的钱，我也要一起还吗？](0269.md)**（第 0269 题）  
  不一定，要看这笔钱是怎么借的、借来干什么。
- **[协议离婚交了申请，过了冷静期就算离了吗？](0270.md)**（第 0270 题）  
  不算。
- **[离婚后，孩子的抚养费该给多少？](0271.md)**（第 0271 题）  
  抚养费没有一个全国统一的数，先由你们两个人商量，商量不成由法院判。
- **[婚前的存款和股票，婚后拿去买了房或者涨了钱，离婚时还算我的吗？](0272.md)**（第 0272 题）  
  婚前的本金还是你的，结婚多少年都不会自动变成两个人的；婚后多出来的那部分要拆开算，拿它买的房能不能算你的，关键看你能不能证明钱的来路。
- **[对方出轨，离婚时我能多分财产、要赔偿吗？](0273.md)**（第 0273 题）  
  有机会，但出轨不等于让对方净身出户，也不等于赔偿稳拿。
- **[离婚后孩子跟谁，法院看什么？](0274.md)**（第 0274 题）  
  法院先看孩子多大，再看跟谁过对孩子最好，谁挣钱多、孩子是男是女，单凭哪一样都定不了。
- **[不离婚，怎么申请人身安全保护令？](0275.md)**（第 0275 题）  
  不用先离婚，也不用先起诉离婚或者打别的民事官司。
