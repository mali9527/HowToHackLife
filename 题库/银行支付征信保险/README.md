# 银行支付征信保险

[人生黑客](../../README.md) › [全部的题](../README.md) › 银行支付征信保险

共 21 道，按题号排。每道题先给答案的第一句，点进去看全文、条件和出处。

- **[银行倒闭了，我的存款能拿回多少？](0092.md)**（第 0092 题 · Hot 100 第 36 名）  
  50 万元以内一分不少拿回来，超出的那部分要从银行清算出来的财产里去分。
- **[银行卡被盗刷，银行说“密码是对的”就可以不赔吗？](0093.md)**（第 0093 题 · Hot 100 第 37 名）  
  不能。
- **[征信上的逾期记录要留多久？](0094.md)**（第 0094 题 · Hot 100 第 39 名）  
  5 年，一般是从这笔欠款还清那天往后数，不是从逾期那天数。
- **[怎么免费查自己的征信？一年能查几次？](0095.md)**（第 0095 题）  
  想看自己的信用报告，在网上查就行，不要钱。
- **[贷款广告说“日息万分之一”，年化到底是多少？](0096.md)**（第 0096 题 · Hot 100 第 38 名）  
  本金全年不变、无其他费用，日息万分之一按365天单利算，年化是3.65%。
- **[银行卡被盗刷了，银行或支付平台承诺过“先行赔付”，怎么让它先赔？](0097.md)**（第 0097 题）  
  能要，而且这句承诺在法院那里算数。
- **[开卡时银行没告诉我开通了网上支付，被盗刷了我也要担责吗？](0098.md)**（第 0098 题）  
  银行在你开卡或者给你开通网上支付的时候没告诉你有这项功能，事后又拿不出你同意用它的证据，这笔网上盗刷的责任你可以不担，告到法院也是支持你的。
- **[给人做担保，合同没写是哪种保证，我要担连带责任吗？](0099.md)**（第 0099 题）  
  合同里对保证方式真没约定，或者约定得不明确，按民法典你担的是一般保证，不是连带。
- **[征信上"连三累六"，还能贷款吗？](0100.md)**（第 0100 题）  
  向商业银行申请贷款，不一定贷不到。
- **[信用卡晚还了一两天，会算逾期上征信吗？](0276.md)**（第 0276 题）  
  不一定。
- **[投保时有小毛病没说，以后会被拒赔吗？](0277.md)**（第 0277 题）  
  不一定，先看保险公司问没问到。
- **[保单受益人写“法定”还是写名字，结果差在哪？](0278.md)**（第 0278 题）  
  我的建议是写名字，几个人就把顺序和份额也写上。
- **[被误导买了保险（说是存款、保本），怎么要回保费？](0279.md)**（第 0279 题）  
  想多要回钱，第一步不是去柜台办普通退保，而是向承保的保险公司提销售误导的异议。
- **[信用卡分期和“免息”贷款，实际年化是多少？](0280.md)**（第 0280 题）  
  每期按初始本金收 0.6%、本金逐月还的分期，实际年化比 7.2% 高不少。
- **[家人买房让我当共同借款人，和当担保人差在哪？](0281.md)**（第 0281 题）  
  差在这笔债是不是你的。
- **[保单买了好几年，保险公司还能以“没如实告知”拒赔吗？](0282.md)**（第 0282 题）  
  多半不能，但“满两年就什么都赔”也不对。
- **[百万医疗险停售了，还能续保吗？](0283.md)**（第 0283 题）  
  能不能续，不看停没停售，看你的合同写的是"保证续保"还是"不保证续保"。
- **[保险公司拿免责条款拒赔，一定有效吗？](0284.md)**（第 0284 题）  
  不一定。
- **[被银行、保险公司坑了，怎么投诉才有人管？](0285.md)**（第 0285 题）  
  最管用的顺序是先投诉那家银行或保险公司本身，把要什么、凭什么写清楚；它拖着不办，或者你对结果不服，再找金融监管总局，打 12378。
- **[风险测评是稳健型，银行却卖我高风险理财，亏了能要求赔吗？](0286.md)**（第 0286 题）  
  能要求银行赔，但凭的不是你亏了，而是银行卖给你的时候没尽到适当性义务，而且你的亏损就是因此造成的。
- **[信用卡只还最低还款额，利息怎么算？](0359.md)**（第 0359 题）  
  只还最低还款额，别指望剩下的钱从到期还款日以后才开始算利息。
