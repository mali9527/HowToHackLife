# 开车撞了闯红灯、乱穿马路的人，我没错也要赔吗？

[人生黑客](../../README.md) › [全部的题](../README.md) › [车辆与交通](README.md)

问答题 · 中等 · 避免损失 · 与行人或非机动车发生事故的机动车驾驶人
依据：法规原文 · 核对于 2026-10-19 · 全国通用；机动车与行人、非机动车之间的道路交通事故

**答案**　没错也不能当然全免，“撞了白撞”这话不对。对方是走路的还是骑非机动车的，规则一样，钱分两层算。第一层是交强险：先由你的交强险在限额内赔，交强险里专门有一档“被保险人在事故中无责任”的赔偿限额，所以认定书上你无责，这一层照样要赔。第二层是交强险赔完还不够的部分：你没有过错，最多承担其中的 10%。这个 10% 是封顶，不是固定按 10% 算，而且是按交强险赔完后的差额算，不是按全部损失算。如果损失是对方故意往你车上撞造成的，你这边不用赔。闯红灯、乱穿马路只说明对方违法，不等于故意，别指望靠这一点全免。还有一处容易想当然：交警的事故认定书写你无责，它是证据，不是最后的结论，具体担多少还要跟保险公司核，有争议由法院定。所以出了事先报警，把现场影像留全，再拿着认定书、损失凭证和保单去找你的保险公司对账。

## 解析

最常见的情形是这样的：你正常开车，对方闯红灯或者横穿马路，被你撞了，交警认定你无责。这时候先走你的交强险。交强险的限额分死亡伤残、医疗费用、财产损失几项，另外还有一档专门给被保险人在事故中无责任时用的限额，所以你无责，交强险这一层也不会是零。每一项具体是多少钱，这一页没讲，看《交强险最多能赔多少？》。交强险赔完还差的那部分才轮到你：你没有过错，承担不超过 10% 的责任。10% 是上限，不能当成固定比例去谈，最后落在多少，看个案的情况。

你要担的这一块，也不一定全从自己口袋里出。顺序是交强险先赔，不够的由商业险按保险合同的约定赔，还不够或者没买商业险的，才由你自己赔。所以买了商业三者险的，下一步是拿保单和完整的保险条款去问保险公司：你没有过错、依法要担的这部分在不在它的责任范围里，有没有免责条款卡着。别以为买了三者险就一定全包，保险公司说不赔，让它把核赔的理由讲清楚。

认定书写你无责，也别以为事情到此为止。认定书是交警根据现场勘验、调查和检验鉴定的结论做的，写明事故的基本事实、原因和各方的责任，它的身份是处理事故的证据。法院会审查它有多大的证明力，对方拿得出相反的证据，是可以推翻的。你到底有没有过错、最后担多少，先拿认定书、现场影像、损失凭证和保单找保险公司核对分担，谈不拢的由法院审理认定。只凭认定书上无责，也不能就说自己一分不用赔。

认定书上你也有责任的，就不是 10% 这一套了。对方没有过错的话，交强险赔完的差额全由你这边担。有证据证明对方有过错，比如闯了红灯，就按对方的过错程度减轻你的责任，过错越大减得越多。前提是“有证据证明”，对方闯红灯、乱穿马路这件事得能拿出来，现场影像和认定书里的记载都是证据。这也是出了事要先报警、把现场影像留全的原因。

损失要是行人或者骑车的人故意撞你的车造成的，你这边不用赔。这时候你这边不担赔偿责任，交强险也不赔，受害人故意造成的损失，保险公司不予赔偿。闯红灯、乱穿马路只能说明对方违法、有过错，不能直接当成故意碰撞。想按故意来主张免赔，光凭对方闯了红灯不够，得把对方是故意撞上来的这件事查明。

你的车要是没买交强险，负担会重很多。本来该由交强险赔的那一块，对方可以要求你这个该投保的一方在交强险限额内自己掏，法院会支持。

- 有证据证明非机动车驾驶人、行人有过错的，对交强险赔偿后的不足部分，根据其过错程度适当减轻机动车一方的赔偿责任（机动车与非机动车驾驶人、行人之间发生交通事故；有证据证明非机动车驾驶人、行人有过错；交强险赔偿后仍有不足；损失不是由非机动车驾驶人、行人故意碰撞机动车造成的）[1] 第七十六条第一款第二项
- 机动车一方没有过错的，对交强险赔偿后的不足部分承担不超过10%的赔偿责任，10%是上限而不是固定比例（机动车与非机动车驾驶人、行人之间发生交通事故；机动车一方没有过错；交强险赔偿后仍有不足；损失不是由非机动车驾驶人、行人故意碰撞机动车造成的）[1] 第七十六条第一款第二项
- 交通事故的损失由非机动车驾驶人、行人故意碰撞机动车造成的，机动车一方不承担赔偿责任（交通事故的损失是由非机动车驾驶人、行人故意碰撞机动车造成的）[1] 第七十六条第二款
- 交强险另设被保险人在道路交通事故中无责任的赔偿限额，不能把机动车一方无责任当成交强险没有赔偿层（已投保交强险的机动车发生道路交通事故，造成本车人员、被保险人以外的受害人人身伤亡或财产损失；被保险人在事故中无责任；损失不是受害人故意造成的）[2] 第二十三条第一款
- 道路交通事故的损失由受害人故意造成的，交强险保险公司不予赔偿（道路交通事故的损失是由受害人故意造成的）[2] 第二十一条第二款
- 属于机动车一方责任的损害，交强险赔偿后不足的部分，由商业险保险人按保险合同约定赔偿；仍然不足或者没有投保商业险的，由侵权人赔偿（机动车发生交通事故造成损害；属于该机动车一方责任；交强险赔偿后仍有不足）[3] 第一千二百一十三条
- 未依法投保交强险的机动车发生交通事故造成损害，受害人请求投保义务人在交强险责任限额范围内赔偿的，人民法院应予支持（机动车未依法投保交强险，发生交通事故造成损害；损失不是受害人故意造成的；受害人请求负有投保义务的人在交强险责任限额范围内赔偿）[4] 第十六条第一款
- 交通事故认定书载明事故基本事实、成因和当事人的责任，是处理交通事故的证据（公安机关交通管理部门根据现场勘验、检查、调查情况及有关检验、鉴定结论制作交通事故认定书）[1] 第七十三条
- 人民法院应依法审查并确认交通事故认定书相应的证明力，但有相反证据推翻的除外（人民法院审理道路交通事故损害赔偿案件，使用公安机关交通管理部门制作的交通事故认定书）[4] 第二十四条
- 不能仅凭交通事故认定书上的无责任就认定机动车一方和保险公司均不用赔，应分别核对交强险的无责任赔偿和机动车一方的民事分担（推论，由 [1][2][4] 合起来读）
- 不能仅凭行人、非机动车驾驶人闯红灯、乱穿马路，就认定其故意碰撞机动车或故意造成损失，从而免除机动车一方或交强险保险公司的赔偿责任（推论，由 [1][2] 合起来读）

没核到：一起事故中机动车驾驶人是否确实没有过错，以及最终应承担的具体赔偿比例和金额；具体商业三者险合同是否覆盖机动车无过错时依法承担的赔偿责任。
