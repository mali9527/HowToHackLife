# 我不在了，苹果账号里的照片谁能拿到？要提前设置什么？

问答题 · 简单 · 避免损失 · 想提前安排身后苹果账户照片访问的人
依据：平台的帮助说明 · 核对于 2026-10-07 · 适用苹果账户，中国大陆未预设联系人时的具体材料须确认

**答案**　你生前设好的遗产联系人，凭访问密钥和死亡证明，经苹果审核后能拿到。照片得存在 iCloud 或云备份里才在范围内。

## 解析

照片不会跟着账号"继承"给家人。苹果给的办法叫遗产联系人：你在世的时候在手机上指定一个或几个人，你去世后，对方拿着访问密钥和你的死亡证明向苹果申请，苹果核实了他的信息才批准。这是苹果在帮助页面上的说法。很多人以为设个联系人就完事了，少了密钥这一步不行。对方手里没有密钥，这条路就走不通。密钥丢了或者忘了放哪，苹果既调不出来，也补不了一个新的。

**能拿到哪些照片**

遗产联系人能看的，是你存在 iCloud 和 iCloud 云备份里的某些数据。iCloud 照片在苹果列的清单上。iCloud 云备份里的内容也能看，里面可能有存在设备上的照片和视频。反过来说，只在手机里、既没存进 iCloud 也没进云备份的照片，不在这个范围里。你哪些照片已经在云端、云备份里包不包括它们，趁现在问一下苹果支持。设了遗产联系人，不等于手机里每一张都能留下来。

照片以外，有些东西对方拿不到。你用自己账户买的影片、音乐、图书，订阅和 App 内购买项目，都不在里面。iCloud 钥匙串里的付款信息、密码和通行密钥也拿不到。

**提前要做的事**

先看设备。你得有一台 iPhone 或 iPad 系统在 iOS 15.2、iPadOS 15.2 或更高，或者一台 Mac 系统在 macOS Monterey 12.1 或更高，先更新到最新版本。设备上要登录你自己的 Apple 账户。双重认证没开的，先打开。

再想好设谁。对方不需要有 Apple 账户，也不需要有苹果设备。对方将来去申请的时候要年满 13 周岁，具体年龄各个国家和地区不一样。打算指定还没成年的孩子，先找苹果支持问清中国大陆的年龄要求。

可以设好几个人，但要知道一点：每一位都能在你去世后单独决定怎么处理你的数据，包括永久删除。设几个人、设谁，照这一点去想。

然后添加。在 iPhone 或 iPad 上，进"设置"，点你的名字，再点"登录与安全性"、"遗产联系人"、"添加遗产联系人"，可能要用面容 ID、触控 ID 或设备密码认证一下。在 Mac 上，从苹果菜单进"系统设置"，点你的名字，再点"登录与安全性"、"遗产联系人"、"添加遗产联系人"，可能要用触控 ID 或 Mac 登录密码认证。

**把密钥交到对方手里**

加好之后会生成访问密钥，这一步最容易漏。交给对方有几种办法。你们俩都开了 iMessage 信息，才会看到"发送 iMessage 信息"这个选项。用它发过去、对方接受了，对方的设备会在他的 Apple 账户设置里自动存一份密钥。用这个办法的，要跟对方确认他收到了。

也可以打印一份纸的交给对方，或者把密钥页面存成 PDF、截个屏发给他，或者把一份副本和你的遗产规划书放在一起。不管用哪种办法交，苹果都建议你再打印一份，和遗产规划书放在一起。

**你走之后，对方怎么拿**

对方要同时拿着访问密钥和你的死亡证明去申请。文件要求各国家和地区可能不一样，比如在日本，要的是一份表明账户持有人已故的亲属证明，不是死亡证明。苹果审核、核实了对方的信息才批准。要等多久、中国大陆会不会再要别的材料，对方按苹果发来的邮件补，进度问苹果支持。

批下来以后，对方拿到的是一个专门的遗产联系人 Apple 账户，用它访问你的数据，不是接手你原来的账户。你原来的账户会失效，用这个账户的所有设备上的激活锁都会解除。对方可以用 iCloud.com 登录看数据，在 privacy.apple.com 下载账户相关的数据。你开了高级数据保护的，对方还要先用遗产账户登录一台 iPhone、iPad 或 iPod touch，再在网页上登录遗产账户，点那台设备上收到的通知授权，才能在网页上查看和下载。

这个遗产账户有期限。从苹果批准第一次遗产联系人请求那天起，能用三年，确认邮件和遗产账户里会写明。过了三年，遗产账户会被永久删除。想留的照片，在这三年里下载下来。

你的手机要是设了密码，苹果没法在不抹掉设备的情况下帮着解锁。所以，遗产联系人这条路能拿到的照片，靠的是存在 iCloud 或云备份里的那一份；只留在手机里的，不在这条路的访问范围内。

**中国大陆的账户**

中国大陆的 iCloud 由云上贵州运营，它的条款写了数字遗产功能：你可以选一名或多名遗产联系人，在你去世后进入你的账户、下载特定数据。联系人是谁、要不要换，由你自己负责更新。

条款也写明，除了数字遗产允许的情况和法律另有规定，账户不能转让，你对账户和里面内容的权利在你去世时终止。苹果收到你的身故证明副本后，账户可能被终止，里面的内容可能被删除，上面说的例外除外。家人想稳妥拿到照片，靠的是你生前设好的遗产联系人。

**没设遗产联系人，或者密钥找不到**

家人还有别的路，但拿不拿得到照片没有保证。苹果有给已故家庭成员请求访问账户的其他办法。它会要求法律文件，核实之后才协助处理，通常包括死亡证明，还可能要法院判令或者别的文件。需要协助的，联系苹果支持。

在中国大陆，条款写明你去世后，近亲属可以按法律规定查阅、更正或删除你的个人信息，通过 digital-legacy.apple.com 联系苹果。个人信息保护法也规定，近亲属为了自己合法、正当的利益，可以查阅、复制、更正、删除死者的相关个人信息，死者生前另有安排的除外。走这条路要交什么证明、能拿到哪些照片、能不能下载副本，家人先在 digital-legacy.apple.com 问清楚再备材料。

所以趁现在把这件事办了：在设置里加一个遗产联系人，把密钥交到对方手里，再打印一份和遗产规划书放在一起。
