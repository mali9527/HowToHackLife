# 孩子拿我的苹果手机乱买东西，怎么提前防住？

[人生黑客](../../README.md) › [全部的题](../README.md) › [常用平台的规则](README.md)

问答题 · 简单 · 避免损失 · 会把自己的 iPhone 交给孩子的家长
依据：平台的帮助说明 · 核对于 2026-10-07 · 全国通用，仅限 App Store 和其他 Apple 服务的购买验证

**答案**　两样一起设，基本就防住了。第一样是把购买密码改成"始终需要"：打开"设置"，轻点你的名字，进"媒体与购买项目"，再轻点"密码设置"，选"始终需要"。这样在 App Store 和苹果其他服务里每买一笔都要输一次密码，哪怕你的账户一直登录着。最容易漏的就在这儿：要是选的是"15 分钟后需要"，你刚输过一次密码，15 分钟之内孩子再买，系统不会再问。第二样是打开"屏幕使用时间"，再进"屏幕时间"里的"App 和网站"，轻点 App Store，把"App 内购买项目"选成"阻止"，苹果 App 内购买的口子就直接关上了。这两步都是苹果帮助说明里的说法。前提是你的 Apple 账户密码只有你自己知道，孩子知道了，"始终需要"也拦不住他。找不到"密码设置"这一项，是你给购买开了面容 ID 或触控 ID，先去"面容 ID 与密码"或"触控 ID 与密码"里，把"iTunes Store 与 App Store"旁边那个开关关掉。

## 解析

先说那 15 分钟，因为它最像防住了、其实没防住。App 里买东西，比如游戏里的道具，买之前要单独验证一次账户，你下载这个 App 时输过的密码不算数。可验证过一次之后，15 分钟内在 App 里再买别的，一般不用再验。假如你刚帮孩子输密码买了一样东西，转手把手机给他，这 15 分钟里他接着点，就不会再弹密码。只有你设了每次购买都要密码，或者开着面容 ID、触控 ID，才是一笔一验。所以"始终需要"不是可选项，让孩子用你的手机，就该是这一档。苹果的帮助也是这么写的：让孩子用你的设备，可以设成每次购买都要输密码。

在"媒体与购买项目"里找不到"密码设置"的，是面容 ID 或触控 ID 开着。开着它，每一笔交易都要刷脸或按指纹验证，也是一笔一验，只是验的不是密码。你想改成输密码，回到"设置"，进"面容 ID 与密码"或者"触控 ID 与密码"，把"iTunes Store 与 App Store"旁边的开关关掉，只关这一个。关完再按答案里的步骤，去"媒体与购买项目"里选"始终需要"。孩子的脸或指纹录进过这台手机的，他能不能借此改你的账户和购买设置，带上系统版本问苹果官方支持，说清录过什么，让他们告诉你这台手机该怎么设。

"阻止"那一步比密码更彻底，它不靠每笔输密码，是直接把 App 内购买关掉。它管的只是 App 内购买，在 App Store 里买 App，还得靠前面的密码那一步。顺序是先打开"屏幕使用时间"，打开以后进"设置"，轻点"屏幕时间"，再轻点"App 和网站"，轻点 App Store，然后轻点"App 内购买项目"，选"阻止"。iPad 也是这么设。我的建议是这一步别省，尤其是孩子常拿你手机玩游戏的。设完还有个口子：孩子自己进设置把"阻止"改回去，或者干脆把屏幕使用时间关了。怎么给屏幕时间单独加一道密码，带上手机的系统版本，查苹果 iPhone 使用手册里"在 iPhone 上创建、更改或移除'屏幕时间'密码"那一节，或者直接问苹果官方支持。

密码这件事要单独说。苹果自己的建议是，只有你本人知道你的 Apple 账户密码、能登录你的账户。孩子要是已经知道这个密码，"始终需要"弹出来他自己就输了，这时候光设"始终需要"不够，要让这个密码重新变成只有你知道的，"阻止"那一步也一起设上。孩子知道的是手机的解锁密码，他能不能凭这个改你的账户密码或者购买设置，同样带上系统版本去问苹果官方支持。

苹果的这些设置只管走苹果结算的购买。孩子用你手机上的微信支付、支付宝买东西，或者在 App 里付钱走的不是苹果的结算，购买密码和"阻止"都挡不住。真出了这种扣款，翻订单或付款记录，看清是哪个平台、哪个支付渠道收的钱，去问那一家的官方客服怎么设购买验证。

孩子要是有自己的苹果手机，路子就不一样了。苹果的家长控制要求孩子用自己的 Apple 账户，不跟家里任何人共用一个。这种情况下想用"购买前询问"让孩子买东西先经你同意，什么条件下能开、怎么设，带上孩子的年龄、账户所属的国家或地区和系统版本，问苹果官方支持。
