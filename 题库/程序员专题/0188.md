# 个人网站上线，怎么判断该备案还是办许可证？

[人生黑客](../../README.md) › [全部的题](../README.md) › [程序员专题](README.md)

问答题 · 中等 · 避免损失 · 准备上线个人网站的人
依据：法规原文 · 核对于 2026-10-18 · 全国通用，限境内互联网信息服务的备案与电信经营许可分类判断

**答案**　先看一件事：你是不是向访问的人收钱，换你提供的信息或者服务。免费给人看公开的内容，比如个人博客、作品集、技术笔记，属于非经营性的，走备案；向用户有偿提供信息，或者在网上收钱给人做网页，属于经营性的，要办互联网信息服务的增值电信业务经营许可证。个人做网站也得备案，用域名访问的要备，只能用 IP 访问的也要备，备案没办好之前不能对外开。备案向你住所所在地的省通信管理局办，最省事的是委托给你的网站提供接入服务的服务商代办。许可证这条路，经营增值电信业务的经营者得是依法设立的公司，你得先有公司，而且公司只是条件之一。最容易翻车的是先按免费网站备了案，后来又加上收费的内容。备案的网站不能做有偿服务，所以加收费之前，要把该备案还是该办证重新判断一遍。

## 解析

个人站多数是第一种情况：写博客、放作品、分享笔记，谁都能免费看。这种就是向上网的人无偿提供公开、共享的信息，按非经营性办备案，不用碰许可证。网站是绑了域名还是只能靠 IP 打开，都在备案范围里。规定的意思是，没备案就不能干，所以顺序是先备案、后上线。备案要交给你住所所在地的省通信管理局，你也可以委托给你网站提供接入的电信业务经营者，比如给你提供服务器接入、机房托管的那家服务商，替你办备案，以后要变更、注销也能让它办。第一步就是找这家服务商要它现在的备案材料清单，问清身份和域名要怎么核验，再对一下你那个省的通信管理局公开的办理要求。

判断要不要办证，看的是"有偿"两个字连着什么。规定说的经营性，是通过互联网向上网的用户有偿提供信息，或者有偿提供网页制作这类服务。走这条路，要向省、自治区、直辖市的电信管理机构或者国务院信息产业主管部门申请互联网信息服务增值电信业务经营许可证，除了这个办法列的条件，还得符合电信条例的要求。其中一条是经营者必须是依法设立的公司，想走这条路就得先有公司。但有了公司也只是够上一个条件，完整的资格、材料，还有注册公司和申请许可谁先谁后，向审批许可的机关要一份现行的申请指南，照着准备。我的建议是，网站只打算免费提供公开、共享的信息，就按个人备案上线，别为了一张用不上的许可证先去注册公司。

收钱的方式不同，对应的可能不是同一张证。电信业务是按分类发许可的，业务分类目录里，"信息服务业务"和"在线数据处理与交易处理业务"就是分开的两类：前者是信息发布、搜索查询、社区、即时交互这些，后者是通过联网的平台给用户做在线的数据处理和交易处理。打赏、卖付费工具、让别人入驻你的网站做买卖，各自算哪一类、要办哪几张，不要自己对号入座。把网站有哪些功能、向谁收钱、收的是什么钱、有没有别人入驻写成一页说明，拿去问省通信管理局，核实了业务分类和要办的许可，再决定怎么上线。

在网上卖自己的东西，和有偿提供信息不是一回事。青海省通信管理局的问答里说，企业在网上卖自己的商品，是销售渠道的一种拓展，不属于经营电信业务，不用申请电信业务经营许可证，做好网站备案就够了，但网站上不应该有收费的广告服务。这是青海省通信管理局的说法，说的是企业网站。你是个人，在网站上卖自己做的东西，或者想接收费广告，以你住所所在地省通信管理局的答复为准，问清楚了再挂收款和广告位。

已经备了案、后来想加收费，这一步最容易出事。规定写明，非经营性的网站不得从事有偿服务。付费栏目、收费的定制服务这类东西，上线之前先按上面的办法重新判断，需要办证的，证办下来之前别开收费。

网站要是涉及新闻、出版、教育这类依法须经主管部门审核同意的内容，审核同意要在申请许可或者备案之前拿到。备案号或者许可证不等于这些审批都办完了。这类网站先向通信管理局和对应的主管部门问清要取得哪些审核同意的文件，再去走备案或者许可。

自己开发的 App 怎么备案，这一页没讲，看"自己开发的 App，备案怎么办？"。

- 电信业务经营按电信业务分类实行许可制度，经营电信业务必须依法取得电信业务经营许可证（在中华人民共和国境内经营电信业务）[3] 第七条第一款、第二款
- 在线数据处理与交易处理业务是单列的增值电信业务类别，包括通过相连的应用平台为用户提供在线数据处理和交易或事务处理（利用与公用通信网或互联网相连的数据与交易、事务处理应用平台，通过公用通信网或互联网为用户提供相应处理业务）[4] B21首段
- 信息服务业务是单列的增值电信业务类别，其类型主要包括信息发布平台和递送、搜索查询、社区平台、即时交互、信息保护和处理等（通过信息采集、开发、处理和信息平台建设，通过公用通信网或互联网向用户提供信息服务）[4] B25首段
- 依法须经有关主管部门审核同意的新闻、出版、教育等互联网信息服务，须在申请经营许可或履行备案手续前取得审核同意（从事新闻、出版、教育等互联网信息服务，且依照法律、行政法规以及国家有关规定须经有关主管部门审核同意）[1] 第五条
- 拟从事非经营性互联网信息服务，应向住所所在地省通信管理局履行备案手续（拟在中华人民共和国境内从事非经营性互联网信息服务）[2] 第三条第二款
- 接入经营性互联网络的非经营性互联网信息服务，可以委托为网站提供接入服务的相关电信业务经营者代为履行备案手续（拟通过接入经营性互联网络从事非经营性互联网信息服务）[2] 第八条
- 未取得许可或未履行备案手续，不得从事相应互联网信息服务（在中华人民共和国境内从事互联网信息服务，依法应当取得许可或者履行备案手续）[1] 第四条第二款
- 从事经营性互联网信息服务，除具备本办法列出的条件外，还应当符合电信条例规定的要求（在中华人民共和国境内从事经营性互联网信息服务）[1] 第六条首段
- 非经营性互联网信息服务提供者不得从事有偿服务（已履行备案手续、从事非经营性互联网信息服务的提供者）[1] 第十一条第二款
- 在网上销售自己的商品是销售渠道的拓展，不属于经营电信业务，无需申请电信业务经营许可证，做网站备案即可；但网站上不应有收费的广告服务业务（网站用来销售经营者自己的商品，不是向上网用户有偿提供信息或者网页制作等服务；这是省通信管理局在问答里对企业网站的解释，个人网站卖自己的东西、平台入驻、收费广告等情形，以住所所在地省通信管理局的答复为准）[5] 第8问

没核到：打赏、付费工具、第三方入驻交易等具体模式分别属于哪种业务，以及应申请哪些许可；公司登记与电信业务经营许可的具体办理先后，以及申请时适用的完整资格、资本和材料清单；依法需要有关主管部门审核同意的具体业务范围、对应文件和办理手续；网站备案最新表单、身份与域名核验材料和具体提交菜单。
