# PIP 没通过，公司就能按“不能胜任”辞退我吗？

[人生黑客](../../README.md) › [全部的题](../README.md) › [程序员专题](README.md)

问答题 · 中等 · 避免损失 · 被以PIP未通过为由辞退的职工
依据：法规原文 · 核对于 2026-10-18 · 全国通用，全日制劳动关系中按不能胜任工作解除劳动合同的情形

**答案**　光凭 PIP 没通过，不能。PIP 是公司内部的一个考核，"未通过"这几个字只是公司给的结论，法律要看的是一串事有没有做齐。先得是你确实干不了这份工作；然后公司给你做过培训，或者给你调过岗位；培训或者调岗之后，你还是干不了。这三步连着，缺哪一步都不行，一张"未通过"的结论替代不了中间那段培训或者调岗。三步都够了，公司还要提前三十天书面通知你本人，不想等这三十天，就得额外多付你一个月工资。公司有工会的，还要事先把辞退理由通知工会。你要是正在孕期、产期、哺乳期，或者在看病的医疗期里，公司就不能拿"不能胜任"这个理由辞你。真闹成劳动争议，要拿证据证明这些的是公司。拿到辞退通知先别急着认，把劳动合同、岗位要求、PIP 的内容、培训或者调岗的记录、前后的考核结果放在一起，拿去问当地人社部门。

## 解析

最常见的情况是这样的：你被拉进 PIP，几个月后 HR 告诉你没通过，接着就说按不能胜任跟你解除。这时候先别跟着 HR 的说法走，把那三步一步一步对。第一步，当初说你不胜任，对照的是哪份岗位要求、哪次考核，你手里有没有。第二步，PIP 期间公司有没有实际给你培训，或者把你调到了别的岗位；培训和调岗做其中一样就行，但总得做过一样。一份 PIP 算不算培训，看它实际做了什么，不看它叫什么名字。第三步，培训或者调岗之后，公司有没有再看你能不能胜任，结果是什么。三步里有一步对不上，"未通过"就撑不起这次辞退。

PIP 要做满几个月、考够几次、多少分算及格，公司才能辞人？别把哪个固定的天数、次数、分数当成全国的硬杠杠，真正要对的是那三步有没有实际做齐。你要弄清的是自己这个岗位：让公司说明适用的岗位要求是什么、考核标准是什么、培训或者调岗是怎么安排的，你拿这些去对那三步。

三步都对上了，公司也不能当天说走就让你走。它有两个办法选一个：提前三十天书面通知你本人，或者不提前通知，额外多付你一个月工资再解除。口头说一声不算书面通知你本人。这一个月工资是替提前通知的那三十天付的，解除之后还能拿多少补偿、N 和 N+1 怎么算，这一页没讲，看「被裁员了，N、N+1、2N 分别是什么情况、怎么算？」。

公司建了工会的，单方跟你解除合同，要事先把理由通知工会。这是通知，不是要工会批准，工会没点头不等于公司辞不了。但公司连通知都没做，你以违法解除为由要赔偿金，法院会支持；只有一种例外，公司在你起诉之前已经把通知工会这一步补上了。所以问人社部门的时候，顺带问一句你们公司有没有工会、通知过没有。被违法辞退之后是要回去上班还是拿两倍赔偿，看「被违法辞退，是要求回去上班，还是拿两倍赔偿？」。

还有几类人，公司不能拿"不能胜任"辞退，PIP 过没过都一样。一是从事接触职业病危害作业、还没做离岗前职业健康检查的，或者是疑似职业病病人、还在诊断或者医学观察期间的。二是在这家公司得了职业病或者因工受伤，并且被确认丧失或者部分丧失劳动能力的。三是生病或者非因工受伤，还在规定医疗期内的。四是女职工在孕期、产期、哺乳期的。五是在这家公司连续干满十五年，而且离法定退休年龄不到五年的，这两个条件要同时满足，只满一个不算。另外，其他法律、行政法规规定的情形也算，这五类不是全部。要分清的是，这些保护挡的是"不能胜任"这一类理由，不是说公司拿什么理由都辞不了你。

因为公司作出的辞退决定闹成劳动争议，举证的是公司。你确实不能胜任、培训或者调岗做过、之后仍不能胜任、通知走到了，这些要由公司拿出证据来，不是由你证明自己能胜任。

- 公司以不能胜任工作为由解除劳动合同，须具备劳动者不能胜任工作、经过培训或者调整工作岗位后仍不能胜任工作的连续条件；培训与调岗是两种替代方式（适用劳动合同法的劳动关系；公司拟以不能胜任工作为由单方解除劳动合同）[1] 第四十条第（二）项
- 公司按不能胜任工作解除劳动合同，还须提前三十日以书面形式通知劳动者本人，或者额外支付劳动者一个月工资后解除；两种通知替代方式择一（公司依劳动合同法第四十条第（二）项解除劳动合同）[1] 第四十条首句
- 劳动者具有劳动合同法第四十二条规定的保护情形时，公司不得依第四十条以不能胜任工作为由解除劳动合同；这一限制不能泛化为任何理由均不得解除（劳动者具有劳动合同法第四十二条规定的保护情形；公司拟依第四十条以不能胜任工作为由解除劳动合同）[1] 第四十二条首句
- 从事接触职业病危害作业而未进行离岗前职业健康检查的劳动者，或者诊断、医学观察期间的疑似职业病病人，属于劳动合同法第四十二条规定的解除保护情形（从事接触职业病危害作业且未进行离岗前职业健康检查，或者属于诊断、医学观察期间的疑似职业病病人）[1] 第四十二条第（一）项
- 在本单位患职业病或者因工负伤，并被确认丧失或者部分丧失劳动能力的劳动者，属于劳动合同法第四十二条规定的解除保护情形（在本单位患职业病或者因工负伤，并被确认丧失或者部分丧失劳动能力）[1] 第四十二条第（二）项
- 患病或者非因工负伤、处于规定医疗期内的劳动者，属于劳动合同法第四十二条规定的解除保护情形（患病或者非因工负伤，处于规定的医疗期内）[1] 第四十二条第（三）项
- 女职工在孕期、产期、哺乳期的，属于劳动合同法第四十二条规定的解除保护情形（女职工处于孕期、产期或者哺乳期）[1] 第四十二条第（四）项
- 在本单位连续工作满十五年，且距法定退休年龄不足五年的劳动者，属于劳动合同法第四十二条规定的解除保护情形；两个条件须同时满足（在本单位连续工作满十五年，且距法定退休年龄不足五年）[1] 第四十二条第（五）项
- 法律、行政法规规定的其他情形，也属于劳动合同法第四十二条规定的解除保护情形；该条列举的前五项不是全部（劳动者属于其他法律、行政法规规定的、用人单位不得依劳动合同法第四十条解除劳动合同的情形）[1] 第四十二条第（六）项
- 公司单方解除劳动合同，应当事先将理由通知工会；这是通知程序，不能将条文改写成须经工会批准（公司已经建立工会组织，拟以不能胜任工作为由单方解除劳动合同）[1] 第四十三条第一句
- 因公司作出的辞退或者解除劳动合同决定发生劳动争议的，由用人单位负举证责任（因用人单位作出的辞退或者解除劳动合同决定发生劳动争议）[2] 第四十四条
- 仅有“PIP没通过”的结果，不能替代不能胜任工作解除所要求的事实；是否满足条件，要看实际是否不能胜任、是否经过培训或者调岗，以及之后是否仍不能胜任，不能仅凭计划名称或者公司给出的结论判定可以辞退（推论，由 [1][2] 合起来读）
- 建立了工会组织的公司按不能胜任工作解除劳动合同，没有事先将理由通知工会的，劳动者以违法解除为由请求支付赔偿金，人民法院予以支持；但公司在劳动者起诉前已经补正通知工会程序的除外（公司建立了工会组织；解除符合劳动合同法第四十条的规定，但没有事先通知工会）[2] 第四十七条

没核到：某一份PIP是否实际构成培训，以及其考核结果能否证明培训或者调岗后仍不能胜任工作；不同行业、岗位统一适用的PIP最低时长、考核次数和通过分数。
