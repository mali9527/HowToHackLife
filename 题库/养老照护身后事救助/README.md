- **[亲人留下的存款，不做公证怎么取出来？](0001.md)**（第 0001 题 · Hot 100 第 78 名）  
  亲人在一家银行里的钱加起来不超过5万元，配偶、子女或者父母备齐材料，同意一次取完本息并销户，就能去柜台取，不用先跑公证处。
- **[亲人去世了，能去银行查他账户里的钱和流水吗？](0065.md)**（第 0065 题）  
  能查，而且查余额比多数人想的省事。
- **[亲人留下的股票，不做公证能过户吗？](0066.md)**（第 0066 题）  
  能，继承公证不是非办不可，不做公证的路有两条，走法很不一样。
- **[亲人去世了，他的公积金能取出来吗？](0067.md)**（第 0067 题）  
  能取。
- **[突然遇到急难，没钱看病吃饭，怎么申请临时救助？](0068.md)**（第 0068 题）  
  直接去出事那个地方的乡镇政府或者街道办申请，别等，人在外地出的事也在出事的地方申请，不用回老家。
- **[办丧事，殡仪馆的哪些收费我可以不交？](0069.md)**（第 0069 题）  
  清单之外的项目、没按规定公示的收费、标价之外加的钱、被捆绑硬塞给你的用品和服务，这几类你都可以不交。
