# 考证前，怎么判断这个证有没有用？

[人生黑客](../../README.md) › [全部的题](../README.md) › [上学资助与职业资格](README.md)

问答题 · 中等 · 少花钱 · 准备付费培训或报考职业类证书的人
依据：主管部门的答复和解读 · 核对于 2026-10-20 · 全国通用；职业资格、能力评价的类别和官方核验，具体就业用途须结合岗位判断

**答案**　交培训费之前，先拿这个证的全称去对国家职业资格目录，再拿招聘要求去问你想去的单位认不认，两头都对上了再考。目录这一头有三层要分清。第一层，目录之外一律不得许可和认定职业资格，不在目录里的证，名字起得再大，也不是国家职业资格。第二层，目录里的证，只有准入类可以跟就业创业挂钩，其余的不能拿来当上岗的门槛。第三层，目录外的证也不能一概说没用：行业协会、学会可以按职业标准做能力水平评价，只是不能借它设就业门槛；符合条件的用人单位或者社会培训评价组织按规定认定、你评价合格拿到的职业技能等级证书，跟职业资格证书效力相同。这是人社部的说法。最容易翻车的地方是把"能查到""国家认可"当成值得考的理由。证能在官方系统里查到，也要再问你要去的岗位用不用得上它。所以顺序是：先问清证书全称和发证或评价机构，对目录和后续调整，分清是哪一类，找到它的官方查询渠道，最后拿岗位要求去问用人单位，再决定钱花不花。

## 解析

最常见的情况是培训机构来推一个证，说考了好找工作。我的建议是先别谈课程，先要两样东西：证书的准确全称，发证或者评价的是哪个机构。说不清这两样的，后面的判断都没法做。拿到全称以后，去对人社部公布的国家职业资格目录，以及后来的调整文件和相应资格主管部门的正式通知。目录保持相对稳定，但会动态调整，网上流传的项目数和清单可能是旧的，别拿它当准。自己对不出这个证在不在目录里、属于哪一类的，拿着全称和发证部门去问相应的资格主管部门，顺便问清考下来以后还要不要办别的执业手续。

证在目录里，接着看它是准入类还是水平评价类，这两类的用处差得很远。目录里能跟就业创业挂钩的只有准入类，你要干的那份工作是不是非它不可、考到以后还要走哪些手续，问资格主管部门。水平评价类不能被拿来当就业创业的门槛，它证明的是你的水平，有没有用，要看用人单位认不认、拿它做什么用。花钱之前先弄清你考的是哪一类。

证不在目录里，先别急着判它没用，再看它是哪一种。一种是行业协会、学会按照职业标准自己做的能力水平评价，这是允许的，它可以说明你的能力，但不能变相当成职业资格来许可认定，也不能借它设就业创业门槛。要是有人说没有这张协会的证就不能上岗，这话跟人社部的口径对不上，先去问资格主管部门。另一种是职业技能等级证书，由符合条件的用人单位面向本单位职工、或者符合条件的社会培训评价组织面向全体劳动者，按规定开展评价后颁发，你评价合格拿到的，跟职业资格证书效力相同。

不管哪一类，考之前都把它的官方查询渠道弄清楚，考完以后也照这个渠道核一遍。人社部给的入口按证书类别分开：

- 人社部门参与实施的专业技术人员职业资格证书，在中国人事考试网（www.cpta.com.cn）首页的"证书查询验证"栏目查。
- 人社部门没有参与实施的专业技术人员职业资格证书，到相应行业主管部门的官方网站查。
- 职业技能等级证书，在技能人才评价证书全国联网查询网站查，地址是 zscx.osta.org.cn 或 jndj.osta.org.cn。
- 技能人员职业资格证书，也在技能人才评价证书全国联网查询网站 zscx.osta.org.cn 查。

职业技能等级证书在技能人才评价工作网上查不到的，先联系颁发证书的评价机构问原因。别的证书查不到，拿着完整的证书信息去问相应的发证部门，别一查不到就认定是假证。

有没有用的最后一关在用人单位。目录能告诉你这个证是什么身份，告诉不了你它能换来多少工资、能不能帮你晋升。拿你想投的岗位的招聘要求去问单位，它认可哪种证书、用来决定什么，是录用的条件、定工资的依据，还是只算加分。问清了，再拿这个答案去跟培训费、考试费比，值不值你自己就能算出来。

- 国家职业资格实行目录管理，目录之外不得许可和认定职业资格[1] 第六问答复第一项
- 国家职业资格目录内，除准入类职业资格外，其他职业资格不得与就业创业挂钩（职业资格已列入国家职业资格目录）[1] 第六问答复第一项
- 行业协会、学会等社会组织可根据市场需要、按照职业标准开展能力水平评价，但不得变相开展职业资格许可认定，也不得借此设置就业创业门槛（行业协会、学会等社会组织根据市场需要、按照职业标准自行开展能力水平评价活动）[1] 第六问答复第一项
- 国家职业资格目录保持相对稳定，实行动态调整[1] 第三问答复首句
- 人社部门参与实施的专业技术人员职业资格证书，可到中国人事考试网首页“证书查询验证”栏目查询（拟核验的是人力资源社会保障部门参与实施的专业技术人员职业资格证书）[2] 第一部分第一段
- 人社部门未参与实施的专业技术人员职业资格证书，可到相应行业主管部门官方网站查询（拟核验的是人力资源社会保障部门未参与实施的专业技术人员职业资格证书）[2] 第二部分第一段
- 职业技能等级证书可通过技能人才评价证书全国联网查询网站查询，官方说明给出的地址为zscx.osta.org.cn或jndj.osta.org.cn（拟核验的是职业技能等级证书）[3] 第一部分“怎么查询”
- 技能人员职业资格证书可通过技能人才评价证书全国联网查询网站zscx.osta.org.cn查询（拟核验的是技能人员职业资格证书）[3] 第二部分“怎么查询”
- 职业技能等级证书在技能人才评价工作网查询不到时，人社部提示先联系颁发证书的评价机构咨询（拟核验的是职业技能等级证书，且在技能人才评价工作网查不到其信息）[3] 第一部分“查不到怎么办”
- 报考前建议先核对证书全称、是否列入职业资格目录及后续调整、资格类别和实施或评价机构，再按证书类别核实官方查询渠道；以求职为目的的，再拿岗位要求向目标用人单位确认该证的用途（推论，由 [1][2][3] 合起来读）
- 职业技能等级认定由符合条件的用人单位面向本单位职工，或由符合条件的社会培训评价组织面向全体劳动者，按照有关规定开展评价并颁发证书；劳动者经评价合格取得的职业技能等级证书，与职业资格证书具有同等效力（评价主体符合条件，并按上述对象范围和有关规定开展职业技能等级认定；劳动者经评价合格取得职业技能等级证书）[1] 第四问答复第一至二段、第五问答复第一段

没核到：某个具体证书目前是否在目录内、属于哪一类，以及取得证书后还需哪些执业手续；具体证书在招聘、工资或晋升中能带来多少收益；各查询系统当前能否正常办理，以及某张证书查询不到的具体原因。

会变的数：国家职业资格目录的项目数及具体项目的类别、实施部门（谁定：人力资源社会保障部会同有关部门，按国家规定调整；去哪查：人力资源社会保障部公布的国家职业资格目录、后续调整文件及相应资格主管部门的正式通知）。
