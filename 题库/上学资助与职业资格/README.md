# 上学资助与职业资格

[人生黑客](../../README.md) › [全部的题](../README.md) › 上学资助与职业资格

共 28 道，按题号排。每道题先给答案的第一句，点进去看全文、条件和出处。

- **[我的档案现在在哪？毕业后该转到哪里？](0011.md)**（第 0011 题 · Hot 100 第 62 名）  
  档案不归你自己拿，学校会照你在毕业去向登记里填的信息把它寄出去，所以离校前你最该做的一件事，是把这一栏填对。
- **[就业报到证取消了，毕业手续现在怎么办？](0084.md)**（第 0084 题 · Hot 100 第 61 名）  
  报到证从 2023 年起就不发了，补办和改派也一起取消，你不用找人去补。
- **[换了工作，人事档案要不要跟着转？](0085.md)**（第 0085 题）  
  不一定要转，先看两件事：档案现在放在哪儿，新工作是什么单位。
- **[毕业找工作，一次性求职补贴怎么领？](0196.md)**（第 0196 题）  
  先看自己在不在国家的名单上，在的话，去学校负责毕业生就业的部门要求职补贴的通知，按通知和当地的清单申请。
- **[求职要交学历证明，怎么用学信网在线验证？](0262.md)**（第 0262 题）  
  你是2002年起毕业的，学历也已经电子注册，那就不用去跑人工认证，自己在学信网免费申请一份《教育部学历证书电子注册备案表》交给公司，公司在网上就能验真。
- **[给孩子报的培训班不想上了，剩下的学费怎么退？](0263.md)**（第 0263 题）  
  先别按"剩几节课乘优惠单价"去跟机构算，退费得先有个由头。
- **[毕业后交了社保，还算应届生吗？](0264.md)**（第 0264 题）  
  交过社保还能不能按应届生报考，要按你考的那一场规定核实。
- **[孩子跟着我在外地上学，怎么在这里参加中考、高考？](0265.md)**（第 0265 题）  
  孩子在这里上学，不等于就能在这里中考、高考，能不能考，看你现在所在的这个省公布的办法。
- **[孩子上幼儿园大班，保教费现在还要交吗？](0266.md)**（第 0266 题）  
  在公办幼儿园读大班，保教费不用交了；在民办园读大班，能减一部分，但不一定全免。
- **[考证前，怎么判断这个证有没有用？](0267.md)**（第 0267 题）  
  交培训费之前，先拿这个证的全称去对国家职业资格目录，再拿招聘要求去问你想去的单位认不认，两头都对上了再考。
- **[助学贷款扣完学费，余款能提作生活费](0374.md)**（第 0374 题）  
  能。
- **[大学预收书费没花完，差额该退给你](0375.md)**（第 0375 题）  
  该退。
- **[大学没读满一学年，剩下学宿费能退](0376.md)**（第 0376 题）  
  能退，但公办高校的学费和住宿费要先分别核清退费资格。
- **[自己花钱学技能，培训费也能申请补贴](0444.md)**（第 0444 题）  
  能，但这笔钱不是给所有自费学技能的人的，也不是学费全报。
- **[第一次考技能证，评价费也有补贴](0445.md)**（第 0445 题）  
  有，但不是谁第一次考证都能领，你得先对上三件事。
- **[考上大学交不起学费，先入学再说](0446.md)**（第 0446 题）  
  能先入学。
- **[大学家里困难，国家助学金平均 3700 不用还](0447.md)**（第 0447 题）  
  家里困难、在读全日制本科或大专的，国家助学金一定要申请，这笔钱是国家给的资助，不是贷款，正常评上了不用还。
- **[大学成绩好家里又困难，励志奖学金一年 6000](0448.md)**（第 0448 题）  
  能拿，但这 6000 元不会因为你家里困难、成绩又好就自动打到卡上，得你自己申请，再按学校的名额跟同学一起择优评。
- **[读研没工资，国家助学金每年 6000 起](0449.md)**（第 0449 题）  
  读研期间你只要没有固定工资，这笔国家助学金差不多是按人头发的，不用证明家里困难，也不看成绩和论文。
- **[本科参军或去基层，学费每年最高补 2 万](0450.md)**（第 0450 题）  
  每年 2 万是封顶的数，不是人人都能领满。
- **[脱贫家庭孩子读职校，雨露计划每年有补助](0451.md)**（第 0451 题）  
  家里是防止返贫致贫对象，或者是还需要继续帮扶的原建档立卡脱贫户，孩子在读中职或高职，这笔雨露计划补助在孩子上学期间每年都可以申请。
- **[退役士兵读大学，国家助学金 3700 直接给](0452.md)**（第 0452 题）  
  退役士兵在普通高校读全日制本专科，国家助学金是全部享受的，每年 3700 元，不用像普通同学那样先认定家庭经济困难、再去争名额。
- **[高中家里困难，免学杂费还有助学金](0453.md)**（第 0453 题）  
  家里困难的高中生，能拿的是两样东西，它们分开看条件，也不是认定了困难就自动两样都有。
- **[读中职三年，国家助学金每年平均 2300](0454.md)**（第 0454 题）  
  符合条件的中职生，从一年级到三年级都能领国家助学金，平均每人每年 2300 元。
- **[中职成绩好，国家奖学金 6000](0455.md)**（第 0455 题）  
  中职国家奖学金是每人每年 6000 元，学校在每年 12 月 31 日前一次性发给你。
- **[在校成绩突出，国家奖学金最高 3 万](0456.md)**（第 0456 题）  
  3 万是博士生的标准，本科生拿不到这么多。
- **[读研除了助学金，学业奖学金别漏](0457.md)**（第 0457 题）  
  别漏，这是另外一笔钱。
- **[校内勤工助学，挣的报酬别少领](0458.md)**（第 0458 题）  
  先弄清你干的是固定岗还是临时岗，这两种岗算钱的办法不一样，拿一个时薪去套，最容易把账算错。
