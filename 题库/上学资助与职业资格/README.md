# 上学资助与职业资格

[人生黑客](../../README.md) › [全部的题](../README.md) › 上学资助与职业资格

共 10 道，按题号排。每道题先给答案的第一句，点进去看全文、条件和出处。

- **[我的档案现在在哪？毕业后该转到哪里？](0011.md)**（第 0011 题 · Hot 100 第 62 名）  
  档案不归你自己拿，学校会照你在毕业去向登记里填的信息把它寄出去，所以离校前你最该做的一件事，是把这一栏填对。
- **[就业报到证取消了，毕业手续现在怎么办？](0084.md)**（第 0084 题 · Hot 100 第 61 名）  
  报到证从 2023 年起就不发了，补办和改派也一起取消，你不用找人去补。
- **[换了工作，人事档案要不要跟着转？](0085.md)**（第 0085 题）  
  不一定要转，先看两件事：档案现在放在哪儿，新工作是什么单位。
- **[毕业找工作，一次性求职补贴怎么领？](0196.md)**（第 0196 题）  
  先看自己在不在国家的名单上，在的话，去学校负责毕业生就业的部门要求职补贴的通知，按通知和当地的清单申请。
- **[求职要交学历证明，怎么用学信网在线验证？](0262.md)**（第 0262 题）  
  你是2002年起毕业的，学历也已经电子注册，那就不用去跑人工认证，自己在学信网免费申请一份《教育部学历证书电子注册备案表》交给公司，公司在网上就能验真。
- **[给孩子报的培训班不想上了，剩下的学费怎么退？](0263.md)**（第 0263 题）  
  先别按"剩几节课乘优惠单价"去跟机构算，退费得先有个由头。
- **[毕业后交了社保，还算应届生吗？](0264.md)**（第 0264 题）  
  交过社保还能不能按应届生报考，要按你考的那一场规定核实。
- **[孩子跟着我在外地上学，怎么在这里参加中考、高考？](0265.md)**（第 0265 题）  
  孩子在这里上学，不等于就能在这里中考、高考，能不能考，看你现在所在的这个省公布的办法。
- **[孩子上幼儿园大班，保教费现在还要交吗？](0266.md)**（第 0266 题）  
  在公办幼儿园读大班，保教费不用交了；在民办园读大班，能减一部分，但不一定全免。
- **[考证前，怎么判断这个证有没有用？](0267.md)**（第 0267 题）  
  交培训费之前，先拿这个证的全称去对国家职业资格目录，再拿招聘要求去问你想去的单位认不认，两头都对上了再考。
