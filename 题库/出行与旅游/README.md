# 出行与旅游

[人生黑客](../../README.md) › [全部的题](../README.md) › 出行与旅游

共 9 道，按题号排。每道题先给答案的第一句，点进去看全文、条件和出处。

- **[火车票什么时候退最划算？](0165.md)**（第 0165 题 · Hot 100 第 71 名）  
  确定不去了就马上退，最划算的是在开车前8天及以上退，一分钱不扣。
- **[火车票是退了重买，还是改签？](0166.md)**（第 0166 题 · Hot 100 第 72 名）  
  车还没开、原票也没改签过，一般先看改签，同样是要收钱的时段，改签费比退票费低一截。
- **[航班延误或取消，退票要不要手续费？](0167.md)**（第 0167 题 · Hot 100 第 73 名）  
  不要。
- **[航班延误了，航空公司管不管吃住？](0168.md)**（第 0168 题）  
  管不管，看延误出在哪一站、因为什么。
- **[没赶上火车，票还能改签或者退吗？](0169.md)**（第 0169 题）  
  车一开，这张票就不能自愿退了，但还能改签一次，别急着认栽。
- **[火车晚点或者停运了，怎么退票才不扣钱？](0170.md)**（第 0170 题）  
  晚点和停运都能退票不扣钱，但两种的期限差得很远，弄混了就可能被按普通退票收退票费。
- **[飞机关了舱门一直不飞，能要求下飞机吗？](0171.md)**（第 0171 题）  
  能要求，但不是坐久了就能走，中间有一道 3 小时的线。
- **[自己分开买的两段机票，前一段延误赶不上后一段，怎么办？](0172.md)**（第 0172 题）  
  真是分开买、不是联程的两张票，后一段按它自己的票规退改，费用你自己出，前一段延误不会让后一段跟着免费。
- **[火车儿童票看身高还是看年龄？](0173.md)**（第 0173 题）  
  看这趟车实不实名。
