# 飞机关了舱门一直不飞，能要求下飞机吗？

问答题 · 中等 · 避免损失 · 关舱门后仍在机上等待起飞的旅客
依据：法规原文 · 核对于 2026-10-17 · 全国通用，起飞前机上延误；具体安排按实际承运航司的应急预案

**答案**　能要求，但不是坐久了就能走，中间有一道 3 小时的线。全国的规定是：机上延误到了 3 小时（含 3 小时），机组又给不出明确的起飞时间，航司就应当安排你下飞机等待，前提是不违反航空安全和安全保卫的规定。这三个条件要同时满足，规定才要求航司安排。最容易算错的是时间：机上延误不是从计划起飞时间往后数，它说的是你在飞机里等的时间超过了机场规定的地面滑行时间，从哪一刻起算要问机组。另一个容易等错的是起飞时间，机组报了一个时间，你得问清它是定下来的还是估计的。所以等得久了，先找乘务员问两件事：机上延误已经多久，有没有明确的起飞时间。到了条件，就要求实际执飞这班飞机的航司按它公布的机上延误应急预案安排下机；机组说暂时不能下，问清卡在哪条限制、接下来怎么安排。下机是航司去协调的事，不是你到点自己开门走。

## 解析

先把这 3 小时怎么数弄清楚。规定里的机上延误，是关舱门以后、起飞以前，你在飞机里等的时间超过了机场规定的地面滑行时间。等的时间还没超过地面滑行时间，就还不叫机上延误。滑行时间是机场定的，所以别看着表从计划起飞时间算满 3 小时就去要求下机。问乘务员的时候问具体一点：按哪个机场的标准算、机上延误从哪一刻起算、到现在多久了。3 小时是含本数的，刚好满 3 小时就算到了。

明确的起飞时间是第二道条件。机组广播说"预计几点起飞"，你可以接着问这个时间是确认了的还是估计的，确认的依据是什么。我的建议是别把等满 3 小时当成一定能马上下机，机组拿出一个确认的起飞时间，这条就不满足了；你要做的是把问到的时间和答复记下来。

开口要求下机时，对象是实际执飞这班飞机的航司，安排按它公布的预案来。每家航司都必须向社会公布机上延误应急预案，里面要写明下机的条件和限制。机组说暂时不能下，别只听一句"不行"，问清是哪条限制、要等什么、之后怎么安排。

飞机还在机位上和已经推出去，下机的难度不一样。拿国航的预案来说，到了下机条件，飞机还停在机位上的，国航安排旅客下机等待；已经推出去的，在不违反航空安全、安全保卫规定的情况下，国航要先得到空管部门同意，再滑回机位安排下机。推出去以后多了空管同意这一步。别的航司的流程不一定和国航一样，以实际执飞那家公布的预案为准，并向机组确认现在能不能滑回去。

就算三个条件都到了，也有不下或者晚点下的情况。国航的预案写了三种：出于空防或者安保需要；国际和地区航班，机场的海关、边检对旅客下机有明确限制；飞机滑回去可能对机场运行秩序造成较大影响。碰上这几种，国航不安排下机或者暂缓下机。其他航司有什么限制，看它自己的预案。

这条规定管的航班是这几类：国内航司在我国境内（不含港澳台）飞的客运航班；港澳台地区和外国航司的航班，只要始发或者经停的是境内（不含港澳台）的机场，也适用。国内航司从境外机场起飞的，当地的法律或者有关部门可能对下机另有限制，能不能下、怎么安排，问实际执飞的航司，别默认一律按 3 小时的规矩办。

事后对航司怎么算时间、该不该安排下机还有争议，找实际执飞的航司或者民航主管部门，问清它这次按的是哪份执行依据。
