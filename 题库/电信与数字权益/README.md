- **[话费里扣了没订过的业务费，怎么要回来？](0347.md)**（第 0347 题）  
  第一步不是退订，是找运营商要一份收费清单，这份清单你开口要，它就得免费给。
- **[小区、健身房只让刷脸进门，怎么要求换别的方式？](0348.md)**（第 0348 题）  
  直接跟物业或健身房说你不同意刷脸，要它给你换一种验证方式，这是你有权要的。
- **[孩子背着家长在游戏、直播里充了钱，怎么要回来？](0349.md)**（第 0349 题）  
  能要，但不是把孩子的身份证一亮就全退，退不退要看三件事。
- **[手机号有合约、是靓号，运营商不让携号转网，合理吗？](0350.md)**（第 0350 题）  
  合不合理，要看运营商拿什么挡你。
- **[推销电话、营销短信，说了“不要”还来，怎么让它停？](0351.md)**（第 0351 题）  
  你说了“不要”，对方就得马上停，哪怕你以前点过同意也一样。
- **[投诉运营商没结果，怎么向工信部申诉？](0352.md)**（第 0352 题）
