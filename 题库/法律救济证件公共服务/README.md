# 法律救济证件公共服务

[人生黑客](../../README.md) › [全部的题](../README.md) › 法律救济证件公共服务

共 8 道，按题号排。每道题先给答案的第一句，点进去看全文、条件和出处。

- **[起诉要回一笔钱，诉讼费要交多少？](0122.md)**（第 0122 题）  
  起诉追讨普通债款，你先要准备的是案件受理费，要 10 万元，标准受理费是 2300 元。
- **[交不起诉讼费，怎么申请少交、晚交或者不交？](0123.md)**（第 0123 题）  
  起诉或者上诉的时候，把一份书面申请和证明你确实交不起的材料一起交给法院，申请缓交、减交或者免交，这叫诉讼费的司法救助。
- **[要的钱不多，起诉能走小额诉讼吗？](0124.md)**（第 0124 题）  
  在基层法院或者它派出的法庭起诉，钱少只是条件之一，能不能走小额诉讼，要看三件事同时成不成立。
- **[借给别人的钱拖了三年多没还，还能要回来吗？](0125.md)**（第 0125 题）  
  多半还能要，先别认栽。
- **[身份证丢了，怎么补办？](0126.md)**（第 0126 题）  
  丢了就去补，人在外省、符合异地受理条件的，不用专门回老家。
- **[收到法院传票，15 天内要做什么？](0127.md)**（第 0127 题）  
  先把起点弄对：这十五天是从你收到起诉状副本的次日算的，不是从传票到手那天算。
- **[民间借贷的利息最高多少算合法？](0128.md)**（第 0128 题）  
  民间借贷没有一个固定的年利率上限，法院支持的约定利率最高到借款合同成立那时候一年期LPR的四倍，超出的那部分利息，出借人去法院要也不支持。
- **[官司赢了对方不给钱，多久内要申请强制执行？](0129.md)**（第 0129 题）  
  两年。
