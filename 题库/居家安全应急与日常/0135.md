# 打过狂犬疫苗，又被猫狗咬了，还要再打吗？

问答题 · 中等 · 更安全健康 · 打过狂犬病疫苗后又被猫狗咬伤的人
依据：官方文件原文 · 核对于 2026-10-17 · 全国通用；狂犬病再次暴露后的预防处置

**答案**　要不要再打，看你上一轮打到了哪一步、打完隔了多久。上一轮还没打完就又被咬了，不用从头来，接着把原来剩下的那几针打完。全程已经打完，从打完那天算还不到 3 个月，一般不需要加强。打完已经满 3 个月，要加强两针：去门诊打针那天算第 0 天，打一针，第 3 天再打一针。打过全程的人，这次也用不着打狂犬病被动免疫制剂，只有严重免疫功能低下的人例外。最容易出事的地方是觉得打过疫苗就没事了，伤口不管。被咬后，伤口还没结痂、没长好，就要先及时、彻底地处理，打没打过疫苗都一样。我的建议是带上以前的接种记录，尽快去狂犬病预防处置门诊，把每一针的日期报给医生，让医生按你属于哪种情况来定。

## 解析

最常见的是以前被咬过，当时把全程打完了，这回又被咬。先算一笔时间：从你打完全程那天数到这次被咬，满没满 3 个月。满了，要加强，但不是再打一整套，是两针，到门诊打第一针的那天就是第 0 天，三天后再去打第二针。没满 3 个月的，一般不需要加强。"一般"这两个字别丢，它说的是大多数人，不是每个人都免。你的免疫状况、正在做的治疗，到门诊先跟医生说清楚，要不要打由医生评估。

被动免疫制剂这件事，只看你以前有没有打完全程。没被咬时提前打的全程也好，被咬后打的全程也好，都算，这回再被咬都不用打被动免疫制剂。严重免疫功能低下的人不在这条里，同样的规则不能套到自己身上，把病情和治疗告诉医生，让医生给方案。

伤口处理不能因为打过疫苗就省掉。伤口还没结痂、没长好，处理越早越好，所以被咬了别拖着等哪天有空再去。等到就诊时伤口已经结痂或者长好了，就不主张再处理伤口，这时候省下的只是这一步，疫苗该怎么打还是按上面几种情况走。

上一轮正打到一半又被咬，最省事：不加针，也不重来，按原来的程序把剩下的几针打完就行。某一针没按时去打也是同样的道理，后面几针按原来的程序往后顺延，不用从第一针重新开始。

有几种情况别自己套上面的规则。以前打过几针记不清了，或者没打完全程、停了很久，规定只说了某一针晚了往后顺延，没说停多久以后就不能这么接着打。还有打完全程之后又加强过的，这次的 3 个月从哪一针算，也要医生定。这几种都把以前每一针的日期、打了几针、在哪里停的告诉门诊，请医生确认这次怎么打，尤其别拿"不到 3 个月不用加强"给自己免掉这几针。

- 再次暴露发生在狂犬病疫苗免疫接种过程中，应继续按原有免疫程序完成剩余剂次（再次发生狂犬病暴露时，仍在狂犬病疫苗免疫接种过程中）[1] 第二十七条“疫苗接种”
- 全程接种狂犬病疫苗后3个月内再次暴露，一般不需要加强接种（已全程接种狂犬病疫苗；再次发生狂犬病暴露距完成全程接种在3个月内）[1] 第二十七条“疫苗接种”
- 全程接种狂犬病疫苗后3个月及以上再次暴露，应于第0、3天各加强接种1剂次狂犬病疫苗（已全程接种狂犬病疫苗；再次发生狂犬病暴露距完成全程接种已满3个月）[1] 第二十七条“疫苗接种”
- 再次暴露后仍应首先、及时、彻底地进行伤口处置（再次发生狂犬病暴露，有未结痂且未愈合的伤口）[1] 第二十七条“伤口处置”；伤口已结痂或者愈合的情形见第七条
- 就诊时伤口已结痂或者愈合，不主张进行伤口处置（狂犬病暴露后就诊时，伤口已结痂或者愈合）[1] 第七条
- 按暴露前或者暴露后程序全程接种狂犬病疫苗者，除严重免疫功能低下者外，暴露或者再次暴露后无需使用狂犬病被动免疫制剂（已按暴露前或者暴露后程序全程接种狂犬病疫苗；不属于严重免疫功能低下者；发生狂犬病暴露或者再次暴露）[1] 第二十七条“被动免疫制剂注射”
- 规范中疫苗接种时间表的第0天指注射当天（按狂犬病暴露预防处置工作规范的疫苗接种时间表理解接种日期）[1] 第十一条“0（注射当天，下同）”的定义
- 狂犬病疫苗某一剂次延迟接种的，后续剂次按原免疫程序相应顺延，无需重新开始免疫程序（狂犬病疫苗全程接种过程中，某一剂次没有按时接种）[1] 第十七条

没核到：既往接种史不清，或者没打完全程、停打时间很长时，剩下的针怎么安排；全程接种后又接种过加强针，之后再次暴露时3个月间隔从哪次接种起算；3个月内一般不需要加强接种的个体例外，以及严重免疫功能低下者的具体预防处置方案。
