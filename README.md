## 答案从哪来

每道题的页尾像论文一样列出依据和出处、原文摘录和最后核对日期。答案依据法规、官方文件、平台的正式规则和权威指南的原文；读不到原文的，依据主管机关的解释或权威媒体的转述，并在题顶写明。题顶标明依据是法规原文、主管部门的答复和解读，还是媒体报道。怎么看，见[出处说明](出处说明.md)；全部的出处见[参考文献总表](参考文献总表.md)。

规则会变，答案有适用范围。办事、维权以官方原文和主管机关的现行规定为准。

## 关于这个项目

小镇做题家这些年一直在做题。上学的时候做学校出的题，毕业以后做社会出的题：租房、签合同、交社保、报个税、看病、买房。成为父母之后，还有父母的题。

学校的题有课本，有老师，有标准答案。后面这些题没有。学校没教过，家里也没人教，每天上班已经够累了，很少有人有时间和精力一道一道去弄清楚该怎么解。

这些题大多是有答案的。有的写在政策和法律法规里，有的写在各个平台的规则里，有的是医疗保健方面已经有定论的常识。我们把它们找出来，写成一道一道的题：题目是你会遇到的事，答案是该怎么做，后面附上出处。

目标是 1000 道，现在还在更新。
