# 人生黑客——低内耗高收益人生指南

每条都有法规原文做依据，写明哪天核对过。

下面这些事现在就能动手，大多几分钟就能办完，领钱的事多半要申请一次。

## 怎么用

下面按领域列出了全部的题，点题目就进；最该先做的在 [Hot 100](Hot100.md)，按一件事的先后排在一起的在[专题](专题/README.md)。每道题先给答案，再讲门道，页尾是依据、出处和原文摘录，页尾还有上一题、下一题和回目录的链接。

先看一道完整的示范题：[买的家电、电脑半年内坏了，要我证明是质量问题吗？](题库/消费与合同/0003.md)（第 0003 题）。

每道题的题顶标着题型（判断题、选择题、计算题、问答题）、难度（简单、中等、困难）、收益（拿到钱、少花钱、省时间、避免损失、更安全健康）和适用的人。

**[检索页](index.html)**：按关键词、领域、题型、难度、收益类型、依据筛题。GitHub 网页上打不开它，下载仓库后用浏览器打开。

## 给你的 AI 用

把这个仓库交给你的 Agent 就行，入口是 [llms.txt](llms.txt)。它读到的和你看到的一样：每道题的结论、条件、出处和原文摘录，页尾“要点和依据”是一层固定格式的事实，每一点都带条件、出处、条款和原文摘录，不用再加工。它该怎么用这些内容回答你，写在 [AGENTS.md](AGENTS.md) 里：以页面为准，页面没讲的说没讲；先看题顶的适用范围，对不上就说没收录；看最后核对的日期，超过一年先提醒可能过时；引用时注明人生黑客第几题、核对日期和链接。想把内容放进收费的产品、用来训练商用的模型，先联系作者。

## 答案从哪来

每道题的页尾像论文一样列出依据和出处、原文摘录和最后核对日期。答案依据法规、官方文件、平台的正式规则和权威指南的原文；读不到原文的，依据主管机关的解释或权威媒体的转述，并在题顶写明。题顶标明依据是法规原文、主管部门的答复和解读，还是媒体报道。怎么看，见[出处说明](出处说明.md)；全部的出处见[参考文献总表](参考文献总表.md)。

规则会变，答案有适用范围。办事、维权以官方原文和主管机关的现行规定为准。

## 关于这个项目

这个项目不仅仅是给我们自己看的，同时也是给我们的 Agent 看的。我会陆续把适合 Agent 直接读取的内容全都开放出来，让我们自己的 Agent 可以很容易地读取相关信息；遇到类似的问题时，无论你用的是哪个 AI，都可以直接读取，更好地帮你做人生里的一个个题目。

之所以选择这样的方向，是因为这些内容都特别适合由 AI 来挖掘、整理和核对。这些内容的原始出处都来自政府网站、相关机构的官网，还有各种法律法规。由 AI 进行反复核对，我觉得这是 AI 特别能发挥价值的地方。

在 AI 时代，我希望这个项目能变成我们大家日常生活的基础数字设施之一，大家能在里面不断添砖加瓦，让我们的生活更简单、更少内耗、更高收益。
